# Homelab Architecture

This section documents the overall architecture and design of my personal homelab infrastructure.

## Objectives

- Build an enterprise-style IT environment.
- Experiment with Windows Server and Active Directory.
- Deploy and manage Linux infrastructure.
- Explore macOS and Windows endpoint management.
- Implement containerised applications.
- Develop infrastructure automation.
- Experiment with local AI and LLM deployment.

## Infrastructure Components

| Platform | Purpose |
|---|---|
| AMD Ryzen 5 | Primary x86 infrastructure |
| Mac mini M4 | macOS and development environment |
| Ubuntu | Linux server infrastructure |
| RHEL | Enterprise Linux experimentation |
| Windows Server | Active Directory and infrastructure services |
| Windows 11 | Domain-joined client environment |
